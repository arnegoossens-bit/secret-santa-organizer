# Secret Santa Organizer, Kerst 2026 (prototype)

Speelbaar prototype van de vernieuwde Secret Santa Organizer in iO-stijl.

- `index.html`: homepage met 3D-hero en scrollanimaties
- `feestje-aanmaken.html`: aanmaakflow in drie stappen
- `sleeroute.html`: Santa's Sleeroute, het adventsspel in three.js

Alle namen, scores en hints zijn voorbeelddata. Er worden geen mails verstuurd en er wordt niets opgeslagen op een server.

Elke pagina is één zelfstandig HTML-bestand. Er is geen build-stap nodig: GitHub Pages serveert de bestanden zoals ze zijn.
